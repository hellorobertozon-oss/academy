# Game audio assets

- `shop-atmosphere.wav` is a quiet 10 second synthesized loop. The game starts it only after the player enables sound.
- `correct.wav` plays after a correct product recommendation.
- `try-again.wav` plays after a wrong recommendation.
- `select.wav` is a short generated selection tone for future interaction polish.

All audio is local to this prototype and uses no external recording or service.
